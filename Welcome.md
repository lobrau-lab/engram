# Welcome to Engram

Welcome! This vault is your local-first second brain.

Try: `engram index` then `engram search welcome`.

## How it works

Markdown files are the source of truth. A SQLite FTS5 index powers full-text search. Threadline can answer questions grounded in these notes with the built-in on-device model on macOS 26+, or a local OpenAI-compatible endpoint you configure.
